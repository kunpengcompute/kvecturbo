# Quick Start

The KVecTurbo quantization algorithm can be used with the openGauss database (7.0.0 RC1 or later) to improve the performance of the HNSW graph algorithm.

The openGauss community document center provides an example of using the KVecTurbo quantization algorithm. The procedure is as follows:

1. Install openGauss.

    For details, see [Simplified Installation Process in openGauss Installation Guide](https://docs.opengauss.org/en/docs/latest/installation_guide/obtaining_the_installation_package.html).

2. Use the openGauss DataVec vector database.

    For details, see [Getting Started](https://docs.opengauss.org/en/docs/latest/getting_started/getting_started.html). Proceed to step [3](#li19663161713104) from the section "Creating the Vector Index".

3. <a name="li19663161713104"></a>Use the KVecTurbo algorithm.

    For details, see the "HNSW-PQ" section in [PQ Feature](https://docs.opengauss.org/en/).
